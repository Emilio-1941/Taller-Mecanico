| Modulo | Archivo / ruta | Responsabilidad | Datos y reglas |
|---|---|---|---|
| Autenticacion | `backend/src/main/java/com/taller/auth/LoginController.java` | Emite un JWT HS256 al iniciar sesion y admite Administrador/Recepcionista. | `JWT_SECRET` debe configurarse con al menos 32 bytes; token con vigencia de 8 horas. Cambio minimo requerido porque el login anterior no emitia JWT. |
| Seguridad | `backend/src/main/java/com/taller/auth/clientes/security/` | Verifica firma, expiracion y rol antes de permitir acceso a `/api/clientes`. | Solo `ADMINISTRADOR` o `RECEPCIONISTA`; errores 401/403. |
| Alta / consulta | `backend/src/main/java/com/taller/auth/clientes/controller/ClienteController.java` | `POST /api/clientes` recibe multipart; `GET /api/clientes` lista registros. | Alta responde 201 y mensaje visible; duplicados 409; validacion 400; foto grande 413. |
| Reglas | `backend/src/main/java/com/taller/auth/clientes/service/ClienteService.java` | Normaliza datos, valida edad contra nacimiento, foto y duplicados. | JPG/PNG/WEBP inspeccionados por firma, maximo 7 MB; correos en minusculas; telefonos normalizados; consulta SERIALIZABLE. Para garantizar unicidad ante escrituras simultaneas, la tabla debe tener indices UNIQUE compatibles. |
| Persistencia | `backend/src/main/java/com/taller/auth/clientes/model/Cliente.java` y `repository/ClienteRepository.java` | Mapeo JPA y consultas de duplicados. | Tabla existente `clientes`; foto mapeada como BLOB; `taller_id` enlaza por FK. Requiere `id` autogenerado y columna `foto` compatible con BLOB. |
| Frontend | `frontend/src/views/RegistroCliente.vue` | Formulario responsivo de datos y fotografia, envio multipart con Bearer JWT. | Valida tamanio en cliente y presenta confirmacion o error. |
| Frontend | `frontend/src/views/ListaClientes.vue` | Consulta y muestra los clientes autorizados. | Usa el JWT guardado por el login; incluye datos de contacto, municipio, edad y taller. |
| Rutas | `frontend/src/main.js` | Registra `/clientes/nuevo` y `/clientes`. | Acceso API esperado en `http://localhost:8080`. |
| Configuracion | `backend/pom.xml`, `backend/src/main/resources/application.properties.example` | Declara Spring Data JPA/Validation; conserva DDL automatico deshabilitado y limita multipart. | Se declararon dependencias; no se instalaron ni descargaron. No se modifica Docker ni se crea SQL. |
